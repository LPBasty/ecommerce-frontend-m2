\# MineShop - El E-commerce de Minecraft



Este proyecto es el MVP de una tienda en línea creada para el curso de Python.



\## Tecnologías

\- HTML5 Semántico

\- Bootstrap 5

\- JavaScript (para el DOM)



\## Cómo ver el proyecto

Descarga los archivos y abre index.html en tu navegador.

Saludos!
